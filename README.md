# FitFuel Supplements & Nutrition

FitFuel is a web-based e-commerce application developed for fitness supplements and nutrition products.  
The system allows users to browse products, manage carts, place orders, and enables admins to manage products and monitor orders through an admin dashboard.

---

# Features

## User Features
- User Registration & Login
- Login using Email or Username
- Product Browsing
- Product Search
- Shopping Cart System
- Checkout System
- Invoice Generation
- Auto-filled Checkout Information
- Purchase History Cookies
- Stock Validation
- Sold Out Product Handling

## Admin Features
- Admin Login
- Admin Dashboard
- Product Management
- Stock Management
- Order Monitoring
- Product Add/Edit/Delete

# Installation Guide

1. Clone the repository:

```bash
git clone https://github.com/your-username/fitfuel.git
```

2. Move the project folder into:

```text
htdocs/
```

3. Start Apache and MySQL using XAMPP.

4. Import the database:

```text
database/fitfuel_db.sql
```

5. Open the project in your browser:

```text
http://localhost/fitfuel
```
